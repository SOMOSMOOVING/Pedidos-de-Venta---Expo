Productos

Descargá el catálogo actual para tenerlo de referencia o como base para editar en Excel.

Importá un Excel (.xlsx) o CSV con columnas Código, Producto, UMV, EAN, Precio (el orden no importa). Si no ponés la columna Precio, los precios que ya estaban quedan como están.
Precio: por unidad, con coma para los decimales (ej. 1.234,50).

Para que el cambio de catálogo llegue a todos los celulares: descargá el/los archivo(s) .json y subilos al repositorio de GitHub (botón Add file → Upload files, en la misma carpeta que el index.html), reemplazando los anteriores. GitHub Pages republica solo en 1-2 minutos y, al reabrir la app con internet, se actualiza sola.

Ojo: los cambios de catálogo que hacés acá valen solo en este celular hasta que subas el .json. Los pedidos, en cambio, van al servidor y los ves desde cualquier lado.
